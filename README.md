# AI 绘画提示词库 v1

基于 Cloudflare Worker + 飞书多维表格 API 的个人提示词管理网站。

## 推荐飞书字段

- 提示词名称（文本）
- 预览图（附件）
- 正向提示词（多行文本）
- 负向提示词（多行文本）
- 分类（单选）
- 风格（单选）
- 模型（单选）
- 标签（多选）
- 来源链接（超链接）
- 备注（多行文本）
- 状态（单选）

字段名不是完全一致也可以，网页会自动识别常见字段名。

## 功能

- 提示词卡片图库
- 图片附件读取与上传
- 搜索、分类、模型、标签筛选
- 一键复制正向/负向提示词
- 新增、编辑、删除并写回飞书
- 飞书修改后按设定时间自动同步网页
- 编辑冲突检测，避免覆盖飞书端刚修改的数据
- 我的收藏（本机浏览器保存）

## 部署

将整个项目推送到 GitHub，Cloudflare Workers 部署命令：

```bash
npx wrangler deploy
```

首次打开网站进入“飞书连接”，填写 App ID、App Secret 和多维表格链接即可。
